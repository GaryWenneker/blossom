# suno-production-blueprint

## Procedure
1. Load original approved lyrics/project content, artist settings and selected Music DNA. Never reuse protected lyrics or melody.
2. Prepare title candidates, styles/genre, exclude styles, sectioned lyrics, mood, instrument orchestration, vocal gender/timbre and arrangement directives.
3. Preserve/surface full current Suno controls: sunoModel, instrumental, maxMode, weirdness (0-100), styleInfluence (0-100), variety (0-100), personalize and duration preset/targetSeconds.
4. Include mixing instructions such as dry versus echo-rich production, room sound, era instrumentation, musical phrasing and dynamic ending as requested.
5. Validate model/parameter support against the current provider interface; historical UI labels are not binding contracts.
6. Save blueprint and creative brief in Studio. If there is no supported Suno generation API, open normal browser or hand the user copyable fields; do NOT claim generated song or bypass browser auth.
7. Once a file is produced/uploaded, attach it to the project, verify metadata and preserve provenance/rights.
